# Echo Location

A simple browser game where you're a bat flying through a dark cave.

You can't see anything most of the time. Press `Enter` to send a sonar ping and briefly reveal what's around you.

Collect fireflies, avoid obstacles, survive, and beat the boss.

## Controls

| Key | Action |
|---|---|
| `←` | Move left |
| `→` | Move right |
| `Enter` | Sonar ping / Start / Restart |
| `← →` | Change difficulty on start screen |

Press `Enter` 5 times quickly during gameplay to activate Disco Mode.

## Features

- Sonar-based gameplay
- Fireflies for points
- Different obstacles
- Power-ups
- Boss at 150 points
- Easy, Medium and Hard difficulty
- Secret Disco Mode
- High score saved with localStorage
- Web Audio sound effects

## Tech

- HTML
- CSS
- JavaScript
- HTML5 Canvas
- Web Audio API
- localStorage

No frameworks, no libraries, no build step.

## Run

```bash
git clone https://github.com/aquamystic7/Echo-Location.git
cd Echo-Location
```
or just search: https://echo-location.xyz/

Open `index.html` in your browser.
